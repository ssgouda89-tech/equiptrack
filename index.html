How EquipTrack works

1. Register equipment
Owner adds an item and creates its QR code.

2. Start a handoff
Current holder enters the next person's name.

3. Receiver accepts
Only after acceptance does the current holder change.

4. Owner is informed
Every accepted handoff creates an owner notification.

5. Return to owner
Owner confirms physical receipt to close the chain.

Demo limitation: this first phone-only prototype stores data in this browser on this device. It does not yet synchronise between different people's phones. We'll connect secure accounts and a shared database in the next stage.
