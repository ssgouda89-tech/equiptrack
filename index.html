How EquipTrack works

1. Register equipment
Owner adds an item and creates its QR code.

2. Start a handoff
Current holder enters the recipient's name.

3. Recipient accepts
In this demo, acceptance is simulated on the same device.

4. Return to owner
Owner confirms the physical return.

Important: this is a browser-only prototype. It does not yet sync between phones, send real notifications, verify email/phone, or provide a secure backend.
